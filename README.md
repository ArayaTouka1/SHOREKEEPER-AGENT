# 守岸人陪伴终端

守岸人陪伴终端是一款 Windows 桌面 AI 角色应用：你可以和不同角色对话、处理本机文件、管理任务与记忆，并在同一个工作区里完成日常写作、表格和资料整理。

当前发布版本：**0.21.0**

## 主要亮点

- **角色化对话**：守岸人、爱弥斯、流萤、嘉神川克罗艾分别使用独立的人格、称呼和语气。
- **本机 Agent**：在明确授权后读取、创建、修改文件，并提供审批和工作区权限控制。
- **文档预览**：支持 PDF、DOCX、PPTX、XLSX、CSV、Markdown 等常见文件。
- **附件协作**：发送附件时会提取内容并交给当前角色分析，适合改文档、整理表格和总结资料。
- **模型可切换**：支持云端 API 与本地模型配置，模型和接口地址在设置中统一管理。
- **语音**：支持角色语音包、系统语音，以及本地 Qwen3-TTS 音色克隆；内置公共参考音色随安装包提供。
- **启动体验**：支持默认开屏动画和自定义开屏视频，点击画面即可跳过。
- **隐私优先**：安装包不包含个人对话、记忆、密钥、模型缓存或开发者目录；这些内容只保存在本机用户数据目录。

## 安装

Windows x64 用户下载 Releases 中的安装包：

- `守岸人陪伴终端-0.21.0-x64-setup.exe`：标准安装版
- `守岸人陪伴终端-0.21.0-x64-portable.exe`：免安装便携版

首次启动后，在「设置」中填写模型 API，或选择本地模型。应用不会预置任何密钥。

## 基本用法

1. 在角色选择器中选择角色。
2. 在对话框输入问题，按 Enter 发送，Shift+Enter 换行。
3. 点击输入框旁的附件按钮，选择需要阅读或处理的文件。
4. 涉及本机文件的操作会显示权限状态；只读模式下会先请求授权，完全权限模式下可直接执行已允许的操作。
5. 在「设置 → 语音」选择语音包、系统语音或本地 TTS，并使用「检测服务」和「试听音色」确认配置。

## 从源码运行

需要 Node.js 20+ 和 Windows 环境：

```powershell
cd app
npm install
npm run dev
npm run typecheck
npm run build
npm run dist
```

构建产物位于 `app/release/installer` 和 `app/release/portable`。版本号由 `package.json`、`package-lock.json` 和 `electron-builder.yml` 统一固定为 `0.21.0`。

## 数据位置

应用运行数据保存在 Electron 的用户数据目录中，包括设置、对话、记忆、任务和本地 TTS 缓存。卸载不会自动删除这些数据，便于重新安装后恢复；如需清理，请在应用设置或系统中手动处理。
